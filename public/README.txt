Instrucciones para las imágenes:

1. Guarda el logo institucional de la empresa como 'logo.png' en esta carpeta (C:\Users\USUARIO\Desktop\antigravity\public\logo.png).
2. Guarda el código QR de Instagram o contacto como 'qr.png' en esta carpeta (C:\Users\USUARIO\Desktop\antigravity\public\qr.png).

El sistema cargará automáticamente estas imágenes tanto en la pantalla web como en las impresiones térmicas de recibos y stickers.
